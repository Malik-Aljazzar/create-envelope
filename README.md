# Create: Envelope compat

Create: Envelope compat is a compatibility mod that bridges **Envelope** and **Create**, allowing pigeon mail systems to be fully automated.

## Features

* Insert and extract items from mailboxes using Create logistics.
* Use Mechanical Arms, Chutes, Funnels, and other Create components to automate mail handling.
* Open packages automatically with Mechanical Saws.
* Package items and apply addresses through automated Create contraptions.
* Build fully automated pigeon delivery networks.


## Compatibility

* **NeoForge 1.21.1** — Available now.
* **Fabric 1.21.1** — Planned for a future release.

## About this fork

This is a fork of [Create: Envelope Compat](https://github.com/multyfora/createenvelope-1.21.1)
by [multyfora](https://www.curseforge.com/members/multyforski), fixed for a bug
where packages addressed by a plain name (rather than an Envelope Address Tag)
were converted into an undeliverable `CustomAddress` and could never arrive.
